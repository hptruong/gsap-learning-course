# 10. Capstone Projects

Projects should appear throughout the course, not only at the end. Complete one checkpoint after each stage before starting a more decorative effect.

## Suggested sequence

1. Core capstone: an accessible hero with a timeline, controlled replay, and no-scroll fallback.
2. Scroll capstone: a feature section with one trigger, responsive `matchMedia`, and no pinned mobile flow.
3. Text or SVG capstone: a single focused reveal with cleanup and semantics intact.
4. Final capstone: a product page that combines only the techniques justified by the content.

## Definition of done

- Every animation has a user or content purpose.
- `prefers-reduced-motion` has a tested alternative.
- No console errors, leaked listeners, or duplicate React animations.
- Layout is usable at mobile width without scroll-jacking.
- Performance is checked on a physical or throttled device.

Use visual inspiration as a constraint to analyze, not a quality grade to imitate.
