# Animation Glossary

| Term | Meaning |
| --- | --- |
| Tween | One animation instance that changes values over time. |
| Timeline | A container that coordinates tweens and playback. |
| Target | An element, object, or collection being animated. |
| Ease | A function that controls rate of change. |
| Stagger | An offset applied across multiple targets. |
| Scrub | Scroll-linked animation progress. |
| Pin | Temporarily fixes an element while scrolling. |
| Revert | Restores GSAP-managed inline values and cleans up context objects. |
| FOUC | Flash of unstyled content before an initial animation state applies. |
| Reduced motion | A user preference to minimize non-essential movement. |

For the complete API vocabulary, use the [official GSAP docs](https://gsap.com/docs/v3/).
