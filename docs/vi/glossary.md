# Animation Glossary

| Term | Nghĩa |
| --- | --- |
| Tween | Một animation thay đổi value theo thời gian. |
| Timeline | Container điều phối tween và playback. |
| Target | Element, object hoặc collection được animate. |
| Ease | Hàm điều khiển tốc độ thay đổi. |
| Stagger | Độ lệch áp dụng cho nhiều target. |
| Scrub | Tiến trình animation liên kết scroll. |
| Pin | Cố định tạm thời element khi scroll. |
| Revert | Khôi phục inline value và cleanup context object. |
| FOUC | Flash of unstyled content trước initial state. |
| Reduced motion | User preference giảm chuyển động không cần thiết. |

Xem [GSAP docs](https://gsap.com/docs/v3/) để tra toàn bộ API vocabulary.
