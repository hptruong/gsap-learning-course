## 💡 Best Practices Summary

1. **Luôn dùng `gsap.registerPlugin()`** trước khi dùng plugin
2. **Cleanup animations** khi component unmount (React)
3. **Dùng `gsap.context()`** để manage scoping
4. **Avoid animating `top/left/width/height`** - dùng `x, y, scale, rotation` (GPU-accelerated)
5. **Respect `prefers-reduced-motion`** cho accessibility
6. **Keep animations short** (0.6-1.2s là lý tưởng)
7. **Use `contextSafe()`** cho event handlers trong React
8. **Every animation must serve a purpose** - không decoration
9. **Test trên real devices** - không chỉ browser simulator
10. **Lenis + ScrollTrigger** = smooth scroll combination tốt nhất 2026
